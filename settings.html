Dedicated Prompter
A separate LLM call reads the chat and writes the image prompt, so the roleplay model never has to emit [[IMG: ...]] markers.
In Dedicated mode [[IMG: ...]] markers are no longer a trigger — the prompter decides on its own, and you can delete the marker instruction from your Post-History Instructions. In Both mode markers win: the prompter stands down on any message that already got an image from one. Every bot message also gets a button for running the prompter by hand.
Switching this also switches which text Restore default writes into Prompter Instructions; an unedited field follows, an edited one is left alone.

How many of this chat's own messages the seeding pass sees on top of the cards — 0 reads the cards only. Re-seed every reruns the pass once the chat has grown that many messages; 0 seeds once. Each re-seed costs one LLM call; hand-edited rows are never overwritten.
Present keeps the card's cast plus anyone named in the target message or history window — someone referred to only as "the innkeeper" may be dropped. It also moves the registry into the changing half of the request, so on a caching backend All is usually cheaper as well as better.
How many messages before the target message the prompter sees; the biggest lever on cost. Anchor stride holds the window's start still between jumps instead of sliding every turn, so cached text stays append-only; 0 slides.
Quotes this many previous prompts back so clothing and injuries carry across images. 1 is the useful value; showing a model its last answer can make it repeat itself — if framing stops varying, drop to 0.
